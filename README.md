# InsightDesk SaaS Dashboard

A portfolio demo for a full-stack-style subscription operations dashboard.

Live demo: https://9tynight.github.io/insightdesk-saas-dashboard/

## What it demonstrates

- React dashboard UI with KPIs, chart, searchable table, and account detail state
- Customer health segmentation and report-export feedback
- Product thinking for SaaS admin tools and internal analytics
- Responsive operational layout

## Tech stack

React, Vite, JavaScript, CSS, lucide-react

## Run locally

```bash
npm install
npm run dev
```

## Portfolio note

This demo uses local sample data for easy review. A production version would connect to authenticated APIs, billing data, support tickets, user accounts, and persistent notes.
